## 4. Update Strategy: Choose One

### Option A: Light Refresh (Traffic decline < 15%, rank 5-10)
- Update stats, dates, screenshots, broken links
- Add 1-2 new H2 sections for missing subtopics
- Add FAQ schema + 5 PAA questions
- Update author bio + "Last Updated" date
- **Target:** Recover to peak in 30-60 days
- **Effort:** 2-4 hours

### Option B: Substantial Update (Traffic decline 15-40%, rank 10-20)
- All of Option A +
- Rewrite intro + conclusion for current context
- Add 3-5 new sections (1,500-2,500 words)
- Add original data/expert quotes/templates
- Full schema suite (Article, FAQ, HowTo, Video)
- New visuals (diagrams, annotated screenshots)
- **Target:** Reach top 5 in 60-90 days
- **Effort:** 8-16 hours

### Option C: Complete Rewrite (Traffic decline > 40%, rank 20+, or content fundamentally wrong)
- New outline based on current SERP
- New angle/differentiator
- All new content (keep only evergreen principles)
- New URL or 301 if structure changes drastically
- **Target:** New page authority, top 3 in 90-180 days
- **Effort:** 20-40 hours
