# Blog Brief Quality Checklist

**Use this BEFORE handing a brief to a writer. Every box must be checked.**

---

## 1. Strategy & Intent (The "Why")

- [ ] **Primary keyword defined** with volume, KD, and parent topic
- [ ] **Search intent confirmed** (Informational / Commercial / Transactional / Navigational)
- [ ] **Target URL decided** (new / updating existing — if updating, audit complete)
- [ ] **Business goal clear** (Traffic / Leads / Sales / Authority / Link bait)
- [ ] **Target audience defined** (Role, stage, knowledge level, pain point)
- [ ] **Unique angle identified** (What makes this different from top 10?)
- [ ] **Content type matches intent** (Guide vs. Listicle vs. Comparison vs. How-to vs. Case Study)

---

## 2. SERP Intelligence (The "What's Ranking")

- [ ] Top 10 analyzed (format, word count, angle, gaps)
- [ ] Content gaps documented (3+ specific opportunities)
- [ ] SERP features mapped (Featured Snippet, PAA, Video, Shopping, etc.)
- [ ] Competitor content ages noted (freshness signal)
- [ ] Domain authority range of top 10 recorded
- [ ] **Winning angle articulated in one sentence**

---

## 3. Keyword Architecture (The "How")

- [ ] Primary keyword assigned to H1
- [ ] 5-8 secondary keywords mapped to H2s
- [ ] 15+ semantic/long-tail keywords listed for natural inclusion
- [ ] PAA questions extracted (8+)
- [ ] TF-IDF / Surfer / Clearscope terms reviewed (if available)
- [ ] No keyword stuffing risk (natural placement mapped)

---

## 4. Outline Completeness (The "Structure")

- [ ] H1 written (compelling, includes primary keyword, ≤60 chars for SERP)
- [ ] Introduction structure defined (Hook, Problem, Promise, Proof, Roadmap)
- [ ] All H2s mapped to secondary keywords
- [ ] H3s provided for complex sections
- [ ] **Talking points per section** (not just headers — what must be covered)
- [ ] Data requirements listed per section (stats, quotes, screenshots, examples)
- [ ] Visual requirements specified (charts, diagrams, screenshots, tables)
- [ ] FAQ section mapped to PAA questions
- [ ] Conclusion + CTA defined

---

## 5. SEO Requirements (The "Technical")

- [ ] Meta title written (≤60 chars, primary keyword front-loaded, click-worthy)
- [ ] Meta description written (≤155 chars, benefit + CTA)
- [ ] URL slug finalized (short, keyword-rich, no dates/numbers)
- [ ] Internal links identified (5+ — specific URLs + anchor text)
- [ ] External authority links identified (3+ — specific URLs + context)
- [ ] Schema types specified (Article, FAQ, HowTo, Product, Review, etc.)
- [ ] Image count + alt text keywords specified
- [ ] Target word count set (SERP average ±15%)

---

## 6. E-E-A-T & Differentiation (The "Trust")

- [ ] Author assigned (name, bio, credentials, photo)
- [ ] **Original data/insight included** (survey, analysis, proprietary data, exclusive quotes)
- [ ] Expert quotes secured (2+ named experts with titles/companies)
- [ ] Real examples/case studies included (not hypothetical)
- [ ] Screenshots/product photos specified (dated, annotated)
- [ ] Author schema + Person schema planned
- [ ] "Last Updated" date field in CMS template

---

## 7. Conversion & Business (The "Money")

- [ ] Primary CTA defined (text, destination, tracking params)
- [ ] Secondary CTAs placed (mid-article, exit-intent, sidebar)
- [ ] Lead magnet / content upgrade created (checklist, template, calculator)
- [ ] Affiliate/partner links mapped (with UTMs)
- [ ] Product mentions natural + strategic
- [ ] Email capture opportunity identified

---

## 8. Writer Enablement (The "Handoff")

- [ ] **Tone/Voice defined** (Professional / Conversational / Authoritative / Friendly)
- [ ] **POV defined** (We/You/They — consistent)
- [ ] **Formatting rules** (Short paras, bullets, bolding, scannable)
- [ ] **Must-includes** listed (non-negotiables from stakeholders)
- [ ] **Must-avoids** listed (competitor names, jargon, fluff, claims without proof)
- [ ] **Examples/References** linked (competitor posts we like, our style guide)
- [ ] **Template assets** attached (Notion, Sheets, Figma links)
- [ ] **Deadline** set (realistic — word count / 500 words per hour + research)
- [ ] **Review process** defined (SEO → Edit → Legal → Publish)

---

## 9. Quality Gates (Pre-Publish Checklist)

*Writer submits draft → Editor checks these before SEO review:*

- [ ] Primary keyword in H1, first 100 words, 2+ H2s, conclusion
- [ ] All secondary keywords placed naturally
- [ ] Meta title/description match brief
- [ ] 5+ internal links with descriptive anchors
- [ ] 3+ external authority links
- [ ] All images have alt text + keyword relevance
- [ ] FAQ schema validates (Rich Results Test)
- [ ] HowTo/Article schema validates
- [ ] Author bio + schema present
- [ ] Reading level ≤ Grade 10 (Flesch-Kincaid)
- [ ] No keyword stuffing (TF-IDF check)
- [ ] No unsourced claims (every stat linked)
- [ ] Mobile preview checked (tables scroll, CTAs thumb-reachable)
- [ ] No broken links (internal + external)
- [ ] Canonical URL correct
- [ ] Indexable (no noindex, robots.txt clean)

---

## 10. Post-Publish (The "Lifecycle")

- [ ] Submitted to GSC / IndexNow
- [ ] Added to XML sitemap (lastmod updated)
- [ ] Internal links FROM cluster pages TO this pillar added
- [ ] Social shares scheduled (X, LinkedIn, Bluesky — tailored copy)
- [ ] Newsletter inclusion scheduled
- [ ] Outreach list created (sources quoted, linked, relevant communities)
- [ ] Ranking tracking added (primary + 5 secondary KWs)
- [ ] Calendar reminder: 30-day performance review
- [ ] Calendar reminder: 90-day content audit
