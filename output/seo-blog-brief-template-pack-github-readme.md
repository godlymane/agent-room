# SEO Blog Brief Template Pack

Turn any keyword into a structured, ready-to-write blog brief in minutes — not hours.

## The Problem

Content teams waste 2-3 hours per article just figuring out *what to write*. Keyword in hand, they stare at blank docs: What's the search intent? What structure ranks? What headers, FAQs, internal links? By the time they outline, momentum is gone.

## The Solution

12 battle-tested Markdown templates that transform a target keyword into a complete SEO content brief — with structure, competitor gaps, header outline, FAQ schema, internal link map, and writer-ready instructions.

---

## What's Inside

### 12 Brief Templates (Markdown)

| # | Template | Use Case |
|---|----------|----------|
| 01 | **Pillar/Cluster Hub Brief** | Core topic pages, topic clusters |
| 02 | **How-To / Tutorial Brief** | Step-by-step guides, technical tutorials |
| 03 | **Comparison / VS Brief** | "X vs Y", "Best X for Y" decision posts |
| 04 | **Listicle / Roundup Brief** | "Top 10 X", "Best tools for Y" |
| 05 | **Case Study / Data Brief** | Original research, customer stories |
| 06 | **Product-Led SEO Brief** | Feature pages, integration docs, templates |
| 07 | **Glossary / Definition Brief** | "What is X" high-volume informational |
| 08 | **Template / Checklist Brief** | Downloadable resources, lead magnets |
| 09 | **News / Trend Brief** | Time-sensitive, trending keywords |
| 10 | **FAQ / People Also Ask Brief** | SERP feature optimization |
| 11 | **Local / Geo Brief** | "X in [city]", near-me searches |
| 12 | **Master Blank Brief** | Any custom content type |

### Each Brief Includes

- **Keyword intelligence block** — primary/secondary keywords, volume, difficulty, intent
- **SERP analysis template** — top 10 competitors, content gaps, angle opportunities
- **Structured outline** — H2/H3 hierarchy with word count targets
- **FAQ schema-ready questions** — pulled from PAA, forums, support tickets
- **Internal link map** — existing assets to link, anchor text suggestions
- **Writer brief** — tone, audience, CTA, style notes, examples to reference
- **Content scorecard** — SEO checklist for editor review

## Quick Start

```bash
# 1. Pick your brief type
cp templates/02-how-to-tutorial-brief.md briefs/target-keyword.md

# 2. Fill keyword intel (volume, intent, difficulty)
# 3. Run SERP analysis (template guides you)
# 4. Build outline from competitor gaps
# 5. Add FAQs from PAA + support tickets
# 6. Map internal links from your content audit
# 7. Hand to writer — they start drafting, not researching
```
