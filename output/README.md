## The Problem This Solves

Most content briefs are either:
- **Too vague** → Writer guesses intent → 3+ revision rounds
- **Too rigid** → Writer can't adapt to SERP reality → Generic content
- **Missing SEO fields** → No internal links, no FAQ targets, no schema notes

These templates solve all three. Each includes:
- Search intent classification + SERP analysis section
- Target keyword + 5–10 semantic variations
- Heading structure pre-mapped to intent
- Internal link slots + external authority targets
- FAQ schema candidates from PAA
- Word count, readability, and formatting specs
- Writer brief + editor checklist (separate sections)
